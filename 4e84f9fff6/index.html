Multi-category open-world video individual counting: qualitative comparison

Each demo plays the evaluation frames of one test video. Every panel shows a method's output on the same frame: categories are colours (names only in the legend), the number on each object is the identity the method assigned, counted per category in the order the method first counts it, so the largest number per colour is that method's count. Chips under a panel give the running count so far against the ground truth (red: over, blue: under). Click a panel to compare it with MARLIN at a larger size.

Mask or box with identity. Colour = category, number = identity (per category, in counting order).

Flashing red: identity switch. A new identity lands on a fish the method had already counted, so the count grows on the same fish.

Striped: duplicate on one fish. Two or more predictions cover the same fish in the same frame; stripes take the colours of the categories involved.

Dots: points without tracks. White ring: annotated fish (ground truth). Dark ring: Molmo2-8B points. A split dot is one spot pointed at for several categories.
